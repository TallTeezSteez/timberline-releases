# Timberline — downloads

Timberline is a first-person survival game for Windows, made by Wyatt. These are **early test builds**: expect missing
features and bugs.

**Download:** [latest release](https://github.com/TallTeezSteez/timberline-releases/releases/latest) → under
*Assets*, click `Timberline-<version>-windows.zip`.

1. Unzip the whole folder (right-click → *Extract All…*).
2. Double-click `Timberline.exe`.
3. If Windows shows **"Windows protected your PC"**, click **More info**, then **Run anyway**. This shows up because the
   game isn't code-signed yet; it isn't a virus warning about this file specifically.

The game checks this page for new versions and shows **Update available** on the main menu. Updating = download the new
zip and replace the old folder (your saves are kept in `%APPDATA%\Godot\app_userdata\Timberline`).

This repo only holds release downloads. Credits and licenses ship inside each zip (`LICENSES.md`).
